## 🚀 Guía Rápida de Uso

1. **¿Qué enviar a cada cliente?**  
   Consultá **`00_MATRIZ_DESPACHO_POR_DESTINATARIO_KOALA.md`**. Allí tenés la tabla exacta con los textos listos para copiar y los PDFs listos para adjuntar para Mikhail, Milton, Rafael González (ICXN) y el Administrador de Dominios.

2. **¿Dónde están los archivos listos para el cliente?**  
   En la carpeta **`00-entregables-cliente/`**, organizados por destinatario en subcarpetas claras, sin tecnicismos innecesarios para el área comercial.

3. **¿Dónde está toda la documentación técnica y comercial completa en un solo lugar?**  
   En **`DOCUMENTO_MAESTRO_COMPLETO_KOALA.md`** (y su versión impresa **`DOCUMENTO_MAESTRO_COMPLETO_KOALA.pdf`**), que reúne 100% de la arquitectura, análisis de consistencia, hoja de ruta, endpoints de API y guión de demostración.
